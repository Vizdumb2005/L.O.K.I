# LOKI audit - 2026-11-04

One-shot, ranked, read-only report (ponytail audit method). The audit itself
changes nothing; issues found while auditing were fixed through the normal PR
path with tests and are listed as resolved, not hidden.

## What this repo does

A consent-based digital-mentalism platform, static-deployed to Pages:
a domain-neutral belief/policy engine (`packages/engine`, 611 LOC), a
performance state machine (`packages/showrunner`), effects as plugins
(The Twelve, Ember Words, and the countdown force), optional on-device
perception, and an optional live LLM conductor reached through a local
budget-guarded proxy. The frontend carries no keys and no endpoint URL;
visitors get the scripted voice.

## Must fix

None open. Four must-fix items were found during this audit and already
fixed on PR #35 with tests:

1. **Method leak to the model (fixed, 80bbee3).** The conductor sent
   `sealedTargetId`/`producedCardId` to the LLM before the seal opened;
   in hosted mode the model would "predict" with the answer in context.
   Now never sent pre-reveal; a unit test asserts the field is null.
2. **Ledger double-billed reasoning tokens (fixed, 80bbee3).** The code
   added reasoning tokens on top of completion tokens, contradicting its
   own doc (OpenAI-compatible `completion_tokens` already include them).
   Test corrected to the true figure ($0.0002775).
3. **Opt-in copy overclaimed the channel (fixed, 80bbee3).** It implied
   voice/audio; the route is text-only. Now: "live written words - text
   only, no voice or audio".
4. **Unbounded rate-limit map (fixed, 80bbee3).** The per-IP map in the
   proxy grew forever on a long-lived process; now bounded.

## Should fix

1. **README is stale.** It claims "82 unit/property tests"; the suite is
   now 502 unit tests across 57 files. The countdown act is not mentioned
   in the intro. Doc-only edit; keep with the next content PR.
2. **Baseten-flavored scripts.** `scripts/llm-budget.ts` header,
   `scripts/llm-proxy.ts` env defaults (`BASETEN_BASE_URL`,
   `BASETEN_MODEL`, `BASETEN_API_KEY`), and `scripts/make-report.ts`
   (~line 290) still name the Baseten route. The active route is Modal,
   but the endpoint shape is unconfirmed until redemption; rename envs
   and headers when the route is live, not speculatively.
3. **Demo-plan drift risk.** `docs/demo-plan.md` step 5 (reservation
   policy) was regrounded twice on 11-04 (a04590c). Treat it as the
   single source of truth for the $3 hard-credit-cap logic; do not
   paraphrase it elsewhere.

## Nice to have

1. `packages/showrunner/src/session.ts` is 1019 lines carrying the phase
   machine, cue building, attunement, seal handling, and recovery. Next
   time it is touched, split cue building from phase logic. Not worth a
   dedicated refactor PR.
2. Live sessions draw a random layout seed by design; reproduction relies
   on tests passing `options.seed`. A debug seed surface would make manual
   repro easier, at low value.
3. `scripts/run-conductor-demo.ts` is uncommitted local tooling; decide
   commit-or-ignore deliberately rather than leaving it in limbo.

## Verdict

Lean. The core is small, tests are dense (502 unit plus e2e gates), and
honest failure is enforced structurally (commit gates, seal verification,
provenance checks, fail-closed budget ledger). No dead weight, duplicate
implementations, or clutter directories found. The recurring risk is docs
drifting from code (test counts, vendor names) - the fix is cultural:
doc updates ride in the same PR as the change that invalidates them.
