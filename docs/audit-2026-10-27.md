## Reproduced defects and fixes

- Camera cancellation: unmount-only guards did not invalidate Stop or restart. A late
  model could revive a stopped lab; repeated permission clicks could compete for streams.
  Each attempt now has an invalidatable generation, duplicate opens are blocked, pending
  permission can be cancelled, and stale results release only their own resources.
  Five controlled Playwright tests cover permission, play, model, navigation and ended
  tracks. The old implementation fails the stop/restart regression. No physical camera
  or remote vision model was used in these tests.
- Observation likelihoods: outlier noise used hypothesis count N instead of answer count
  K/channel alphabet V. Likelihood rows and policy predictive mass were not normalized.
  Uniform noise now uses K/V. A useless question now has zero information gain. Policy
  expected entropy also applies the same temperature as the actual update. Four new
  regressions failed before the fix. Existing threshold/noise settings were not retuned.
- Patter: an unsafe template was its own offline fallback. It now falls back to a fixed
  honest sentence. Offline regression failed before the fix, passes afterward.
- Export: reaching `done` discarded an already completed reveal in the audit log. The
  completed outcome is now retained; hidden pre-reveal candidates remain hidden.
- Input validation: missing/negative/non-finite priors, non-finite answer reliability,
  and values outside a channel's alphabet now fail explicitly instead of contaminating
  belief calculations. Three added input tests pass.
- Provenance: the previous checker compared only five metrics of nine cells and ignored
  seed/run metadata. It now checks all fields of all 33 cells, exact order/count and
  metadata, from a shared declarative specification. Controlled mutations of meanProbes
  and seedBase were both rejected. Originals were restored after each mutation.
- Held-out checking: both 95% upper-bound shipping gates are enforced, zero commits cannot
  pass the conditional gate, a failed gate exits nonzero, and seed robustness is not
  described as human generalization. The held-out script's historical label typo is fixed.
- Documentation: current README/results refreshed; old handoff/lessons marked historical;
  the old artifact-timing root-cause claim is marked unproven. The report's Brier interval
  description is corrected from bootstrap to the implemented normal approximation.
